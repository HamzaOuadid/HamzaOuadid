## About

AI / data platform engineer with 2 years shipping production LLM systems inside a regulated enterprise environment — owning everything from ingestion pipelines and retrieval APIs to Kubernetes deployment and the on-call hardening that follows. I build systems that are **measured, not asserted**: every project ships with an evaluation harness and a committed baseline.

**Focus areas:** RAG architecture & hybrid dense/sparse retrieval · rank fusion & cross-encoder reranking · retrieval evaluation (recall@k, MRR) · Model Context Protocol (MCP) server development · forecasting & decision-aware promotion gates · hallucination mitigation
